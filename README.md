# automacao-export-faturas

Sistema desenvolvido em Python para leitura, extração e processamento automatizado de faturas de energia elétrica em formato TXT/SAP.

📌 Objetivo

Automatizar a extração de informações de faturas da Enel/Eletropaulo, reduzindo processamento manual e facilitando auditorias, análises de consumo e validação de cobranças.
